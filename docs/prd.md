# [PRD] 수원시 도서관 서비스 접근성 및 사용성 개선 프로젝트

## 1. 프로젝트 배경

현재 수원시 도서관 사이트는 행정 중심의 **'도서관 사업소'**와 기능 중심의 **'개별 도서관 포털'**이 이원화되어 운영되고 있습니다. 이로 인해 '지하철 무인 대출(책나루)'과 같은 핵심 서비스를 이용하려는 사용자들이 복잡한 탐색 경로와 모호한 용어 때문에 서비스 진입 단계에서 이탈하는 문제가 지속적으로 발생하고 있습니다. 본 프로젝트는 서비스 명칭의 직관성을 높이고 사용자 여정을 단순화하여 디지털 소외 계층을 포함한 모든 시민의 도서 이용률을 높이는 것을 목표로 합니다.

---

## 2. 문제 정의

- **용어의 불일치:** '지하철 무인 대출'이라는 목적어 대신 '책나루'라는 고유 명사만 노출되어 직관적인 인지를 방해함.
- **환경의 오해:** PC/모바일 공용 웹임에도 '모바일 도서관'이라는 명칭을 사용하여 특정 기기 전용 서비스로 오인하게 함.
- **정보 구조(IA)의 파편화:** 사업소 메인에서 실제 기능 페이지까지 4단계 이상의 복잡한 이동 경로가 존재함.
- **안내 가이드 부재:** 정회원 승인을 위한 '오프라인 도서관 방문' 필수 절차가 사전에 고지되지 않아 사용자의 헛걸음과 불만을 초래함.

---

## 3. 핵심 UX 가설

> **가설:** 만약 우리가 '책나루'라는 고유 명칭을 '지하철 무인 대출'로 변경하거나 병기한다면, 사용자들은 서비스 인지 시간을 단축하는 긍정적인 결과를 얻을 것이다. 왜냐하면 사용자의 목적 언어와 시스템 언어가 일치하기 때문이다.

---

## 4. 타겟 페르소나

- **이름/나이:** 박철수 (62세)
- **특징:** IT 숙련도 낮음(Low). 일상적인 앱 사용은 가능하나 공용 서비스의 복잡한 용어에 거부감이 큼.
- **이용 목적:** 퇴근길 지하철역 무인 대출 서비스 이용.
- **핵심 고충(Pain Point):** '책나루'가 무엇인지 몰라 10분간 헤매다 서비스를 포기함.

---

## 5. 핵심 요구사항 및 기능 명세

### 5.1 서비스 명칭 및 레이블 개선

- **[REQ-01]** 메인 및 메뉴의 '책나루' 명칭을 **'지하철 무인 대출(책나루)'**로 일괄 병기한다.
- **[REQ-02]** '수원시 도서관 모바일' 레이블을 기기에 독립적인 **'수원시 통합 도서관'**으로 변경한다.

### 5.2 정보 구조 최적화 (To-Be Task Flow 반영)

- **[REQ-03]** 도서관 사업소(메인) 사이트 최상단에 **'지하철 예약 대출' 바로가기 퀵 메뉴**를 배치한다.
- **[REQ-04]** 개별 도서관 사이트를 거치지 않고 통합 검색 및 예약 페이지로 즉시 연결되는 다이렉트 링크를 구현한다.

### 5.3 프로세스 가이드 시각화

- **[REQ-05]** 서비스 상세 페이지 및 회원가입 완료 화면에 **'도서관 방문 인증 필수'** 안내를 인포그래픽 형태로 제공한다.
- **[REQ-06]** 정회원이 아닌 사용자가 예약 버튼 클릭 시, 실패 팝업 대신 **'가까운 도서관 위치 찾기 및 인증 방법 안내'** 버튼을 노출한다.

---

## 6. 성공 측정 지표 (KPI)

1. **서비스 도달 시간 (Time to Task):** 메인 접속 후 지하철 대출 예약 페이지까지 도달하는 평균 시간 50% 이상 단축.
2. **전환율 (Conversion Rate):** 안내 페이지 접속자 대비 실제 예약 완료 버튼 클릭률 증가.
3. **이탈률 (Bounce Rate):** 메인 페이지 및 메뉴 탐색 단계에서의 이탈률 감소.
4. **CS 민원 감소:** 정회원 자격 요건 오인지로 인한 오프라인 현장 민원 발생 건수 감소.
